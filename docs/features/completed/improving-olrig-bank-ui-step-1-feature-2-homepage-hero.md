# Feature 2 — Image-led Homepage Hero

## Parent epic

[Improving the Olrig Bank UI — Step 1](./epics/improving-olrig-bank-ui-1.md)

## Objective

Give the homepage a photographic, accommodation-led opening with a concise
proposition and clear routes to requesting a stay or comparing stay options.

## Scope

- Use `View of front of house-no-cyclists-hero.jpg` as the candidate image.
- Present one heading, one short supporting sentence and two actions.
- Link Request a stay to `/book/`.
- Link View ways to stay to a stable homepage fragment.
- Provide responsive cropping, stable dimensions and WCAG AA text contrast.
- Preserve the original and uncropped photographs.

## Acceptance criteria

1. The property remains recognisable at phone, tablet and desktop widths.
2. Hero wording does not imply confirmed availability or instant booking.
3. Both actions are ordinary server-rendered links.
4. The image is responsive and does not cause material layout shift.
5. Text remains readable across the final image crop.
